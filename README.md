Project Overview

This project is an Interactive Sales Analysis Dashboard created in Microsoft Excel for Ferns & Petals (FNP) — a gifting company specializing in products for occasions like Diwali, Raksha Bandhan, Holi, Birthdays, Anniversaries, and Valentine’s Day.



![Sales  Analysis Dashboard](Snapshot_of_Sales_Analysi.png)




The goal of this project was to analyze sales performance, customer behavior, product trends, and delivery insights to support data-driven business decisions.

🚀 Key Business Objectives

The dashboard answers important business questions such as:

💰 Total Revenue Generated
📦 Total Orders Analysis
🚚 Average Order Delivery Time
📈 Monthly Revenue Trends
🎉 Revenue by Occasion
🛍️ Top Performing Products
🏙️ Top Cities by Orders
👥 Customer Spending Analysis
⏰ Revenue by Order Hour
📊 Category-wise Revenue Comparison
🖼️ Dashboard Preview

🛠️ Tools & Technologies Used
Microsoft Excel

Excel Formulas
Interactive Dashboarding
📂 Dataset Used

The project uses:

Orders Data
Customers Data
Products Data
📊 Key Insights Derived

✅ Total Revenue exceeded ₹35 Lakhs

✅ Average Customer Spend was approximately ₹3,500

✅ Anniversary & Raksha Bandhan generated the highest revenue

✅ Soft Toys & Sweets were top-performing categories

✅ Peak order activity occurred during evening hours

✅ Average delivery time was around 5.5 days

✅ Certain cities consistently contributed higher order volumes
